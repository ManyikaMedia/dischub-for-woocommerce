# DiscHub for WooCommerce

Accept EcoCash and InnBucks payments seamlessly via DiscHub Payment Gateway on WooCommerce.

## Features
- **EcoCash Direct Payments**: Instant USSD PIN prompt directly on customer phones.
- **InnBucks QR & Code**: Generates instant payment code and QR authorization code.
- **Multi-Currency**: Supports USD and ZWG (Zimbabwe Gold).
- **WooCommerce Blocks & HPOS Ready**: Fully declared and compatible.
- **Seamless On-Site Verification**: Real-time polling and IPN webhook verification.
